# Memora — AI-Powered Spaced Repetition Flashcard App

---

## Overview
- AI generated flashcards using Ollama (Local) and Groq API 
- Manually created flashcards  
- FSRS scheduling algorithm
- Streamlit UI 

---

## Installation

Follow these steps to get the environment running on your local machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/mir-src/srs-card-gen.git](https://github.com/mir-src/srs-card-gen.git)
   cd srs-card-gen

2. **pip install -r requirements.txt**

3. **Set up your environment variables:**
Creanswerate a **.env** file in the root directory and add your Groq key: GROQ_API_KEY=your_key_here

4. **Launch the app:**
   ```bash
   streamlit run app.py
